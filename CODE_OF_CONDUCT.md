# Code of conduct

This project is a place for people who want to build game-playing AI that helps people, including players whose hands can't keep up with a game. Everywhere in it (issues, pull requests, discussions, reviews):

- be respectful and assume good intent; criticise ideas and code, not people;
- no harassment, hate, threats, sexual content or discrimination of any kind;
- don't share anyone's personal data, API keys, private recordings or screenshots;
- don't ask for help with uses that the [LICENSE](LICENSE) or [RESPONSIBLE_USE.md](RESPONSIBLE_USE.md) forbid;
- be patient: this is a one-person project and replies can take a few days;
- write so that a beginner can follow you, in English or Arabic.

**Enforcement.** The maintainer may edit, hide, lock or remove anything that breaks these rules, decline a contribution, and block repeat offenders. To report a problem privately, use the contact on the GitHub profile [@hesham88](https://github.com/hesham88).
